## Overview

Work Tab replaces RimWorld's simple 1-4 priority work panel with a detailed configuration interface supporting priority values from 1 to 9, fine-grained time scheduling for work periods per colonist, drag-to-set priority across multiple pawns simultaneously, and a master overview of all assigned work responsibilities at a glance.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **RimWorld Work Tab** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **1-9 Priority Scale** | Nine priority levels replace the default four for finer work ordering |
| **Time Scheduling** | Set active work hours per colonist for each individual work type |
| **Drag Assignment** | Click-drag to assign identical priorities across multiple colonists |
| **Master Overview** | Colony-wide work assignment grid with priority values per cell |
